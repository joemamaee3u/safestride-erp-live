# StrideSafe ERP

Build a professional web-based ERP application called StrideSafe ERP for a fictional men's reflective running gear company.

Use React, TypeScript, and Tailwind CSS. The application will connect to an external Supabase PostgreSQL project.

Design a modern, polished ERP dashboard with a dark navy sidebar, white main content area, charcoal typography, and electric lime accents. Use responsive layouts.

Create navigation for Dashboard, Point of Sale, Sales Orders, Returns & Exchanges, Inventory, Barcode Operations, Production Orders, Purchasing & Suppliers, MRP, Customers, Financials, Reports, and Settings.

Also create a separate customer-facing online storefront with a product catalog, shopping cart, customer account area, and pickup ordering interface.

The company operates three locations:

Provo Retail Store

Salt Lake City Retail Store

Main Distribution Warehouse

For now, build the navigation, layouts, and page structures only. Do not create fake completed transactions, simulate database persistence, or claim that backend features work. Show clear empty states until Supabase is connected.

Make the interface easy to use during a live demonstration.
